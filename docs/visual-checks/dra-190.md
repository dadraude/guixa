# DRA-190 · T39 ordering visual pilot

Observed 2026-10-25 (Europe/Madrid), on `feature/dra-190-scoped-theme-ordering-pilot`.
This is a visual review checkpoint. Human approval for T40 is still pending.

## Reproduce

From this worktree, verify `.env` uses `DB_DATABASE=guixa_test_dra190`, run `composer install`,
`pnpm install --frozen-lockfile`, then `pnpm build` to provide the app's locally bundled Instrument Sans
files. Start `pnpm exec vp dev --config .vitest/dra190-visual/vite.config.ts` and open
`http://127.0.0.1:5179/.vitest/dra190-visual/index.html`. Select scenarios, appearance and text size
in the fixture controls. Query parameters `scenario`, `mode`, `text`, `controls=0`, `overlay=1`,
`fallback=1`, `hold=1`, `probe=1` and `open=dialog` make captures and computed-style probes
reproducible. The fixture mounts the real AppLayout, Orders pages, order/pickup components,
Welcome component and CSS. Its Inertia page props, navigation and requests are
mocked; the screenshots are not authenticated end-to-end evidence and save does not persist data.

200% root text (32 px) and the settled pickup. At 1280 px it was 1280 or less. The order header
wraps its icon above text when 200% text leaves too little width. The fixture's system mode resolved
dark because the browser reported `prefers-color-scheme: dark`. The local font stylesheet contains
Instrument Sans faces and was served from the build; the fallback capture removes it and still wraps
without horizontal overflow. In installed headless Chrome with `probe=1`, `document.fonts.load()`
reported loaded faces and `document.fonts.check()` returned true. Georgia is applied only to page and
prominent section headings; body, forms, navigation and amounts retain the Instrument Sans stack.

## Contrast and focused regression

Calculated WCAG contrast from the token pairs: light body 12.15:1, card 13.25:1, primary
button 7.40:1, muted text 6.37:1; dark body 13.52:1, card 11.71:1, primary button 9.76:1,
muted text 6.49:1. The real editor error text resolves to `rgb(158, 52, 46)` on light cream
(6.35:1), and `rgb(241, 154, 143)` on dark background (7.19:1). The quantity input now uses
the card fill on both appearances; its unfocused border resolves to `rgb(112, 132, 106)` on
`rgb(255, 253, 248)` (3.97:1) in light mode and `rgb(147, 165, 140)` on `rgb(38, 50, 38)`
(5.11:1) in dark mode. Its keyboard focus border/outline resolves to `rgb(63, 93, 58)` (7.28:1)
light and `rgb(189, 213, 168)` (8.46:1) dark against the same fills. The sage sidebar boundary
is 3.31:1. Disabled buttons retain the existing disabled semantics and are identifiable by their
labels and context.

`php artisan test --filter=OrdersPagesTest` passed 25 tests / 223 assertions on the isolated test
database. Four focused frontend test files passed 18 tests. The mounted editor test
checks Enter sends the explicit per-line PUT with `quantity`, `only: ['order', 'errors']` and
`preserveScroll`. Existing HTTP and SSR checks cover role access, routes, marked removal, cancelled,
pickup and read-only stock/return presentation. Full suites, full type analysis and CI remain pending.
