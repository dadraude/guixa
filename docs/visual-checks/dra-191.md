## Reproduce

In this worktree, verify `.env` has `DB_DATABASE=guixa_test_dra191`, install locked dependencies,
then run `pnpm exec vp build` to provide the locally bundled Instrument Sans stylesheet. Start
`pnpm exec vp dev --config .vitest/dra191-visual/vite.config.ts` and run
`node .vitest/dra191-visual/check.mjs`. The fixture URL is
`http://127.0.0.1:5180/.vitest/dra191-visual/index.html`; query parameters `scenario`, `mode`,
`empty`, `error`, `processing`, `sent`, `text`, `long` and `fallback` select cases. Run the checker with
`--focus-only` to repeat the original cutoff keyboard Tab probe, `--review-only` for the
expanded 200% text, keyboard and long-name cases, or `--wallet-review` for the wallet desktop
200% containment cases. The fixture mounts real AppLayout and T40 page
components and CSS with mocked Inertia props and form transport. Screenshots show rendered
presentation; they are not authenticated end-to-end or persistence evidence.
