## Review round 1 corrections

- **Form gaps:** A computed-style probe confirmed the panel rule had overridden `gap-6` on cutoff and producer product forms. The shared `.pilot-layout-form` rule now yields 24 px at 100% text and 48 px at 200% on cutoff, create, edit, and both wallet manager forms.
- **Amounts:** Both wallet roles and the product table were checked at 375 px, 1024 px/200% and 1280 px. Reflowed amount cells now compute `text-align: end`; their mobile labels compute `text-align: start`.
- **Titles:** Direct and nested T44 headings compute 24 px with zero bottom margin at 100%, and 48 px with zero bottom margin at 200%. The outside-scope `Manage/Settings` heading retains its 32 px bottom margin in the measured case.
- **Dashboard roles:** The fixture now supplies only the matching role's member data, pending pickups and manager summary. Every dashboard case waits for a rendered-section assertion: member actions only for members, producer actions only for producers, manager actions and cooperative summary only for managers, and pending pickups only for the populated member case.

The focused browser probe asserted these computed values and rendered sections across 18 route/role/viewport cases. The final shared visual matrix and verifier were rerun on the amended HEAD.
