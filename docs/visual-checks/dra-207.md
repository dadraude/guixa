# DRA-207 catalogue visual check

The task fixture renders five Manager views with explicit Manager role areas and the existing Manager shell: producer index, stock create, stock index, stock edit, and stock movements. The creation view fixes the supplying producer from its route context. The stock index links back to the producer list for creation.

The [manifest](../../resources/js/fixtures/dra-207.visual.json) declares 60 cases: six populated combinations for each view (375 and 1280 px in both themes at 100% text, plus 1024 px in both themes at 200% text), and two combinations for each owning-page risk state. Risk states cover empty, long content, validation error, pending submit, no search match, and the open edit dialog where applicable. The fixture mocks only error and pending form responses; catalogue and ledger persistence and authorization are covered by HTTP and repository tests.

Preliminary browser measurements on the task fixture found no document horizontal overflow in the five populated views or the 15 risk states at 375 px/100% and 1024 px/200%. All risk states reached their ready marker and retained a focus target. At 375 px, the fixture opened the mobile sidebar to assert that the real Manager stock navigation renders, then closed it before measurement. The edit dialog opened at both 375 px/100% and 1024 px/200%; its close button returned focus to the stock row trigger. The visible stock status switch is inside a 44 px high label, and the shared variable-quantity checkbox is paired with a 44 px high label/row. Measured text contrast on the stock index was 13.66:1 (light) and 14.8:1 (dark); the add-stock action was 6.33:1 and 8.77:1 respectively. The page content uses the existing Nunito Variable pilot theme face.

The committed-HEAD shared visual runner writes its report and contact sheet to the task's ignored `.atl/dra207/visual-final` directory. The matching verifier result and inspection ledger are retained in `.atl/dra207/evidence.md`.
