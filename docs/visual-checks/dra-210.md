# DRA-210 basket UI coverage plan

The T55 pages use the existing Manager shell. `/finance/baskets` is the only basket route family in this slice and remains Manager-gated. Wallet statements retain their existing Manager and Member roles; a member sees the basket id as source text, while a Manager may follow the basket link.

## Component reuse

| Pattern                                | Source and decision                                                                                                                                                                                                                                                                                                                                    |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Page title, description and breadcrumb | Reuse `resources/js/components/Heading.vue`, `resources/js/layouts/AppLayout.vue` and the existing `pilot-layout-page` shell from `resources/js/pages/Manage/Pickups/Index.vue` and `Show.vue`.                                                                                                                                                        |
| Basket list/status                     | Reuse `resources/js/components/ui/badge` and the `pilot-list`/`pilot-list-row` styling from pickup stock lines; no new list component.                                                                                                                                                                                                                 |
| Household selection and stock form     | Reuse `resources/js/components/FormSelect.vue`, `resources/js/components/ui/input`, `button`, `InputError.vue`. Extend `resources/js/components/pickup/StockLines.vue` with the structurally identical `BasketStockLineRow` input and a translated empty-message prop; preserve all pickup consumers. Basket options use the existing `StockLevelRow`. |
| Totals, balance and statement          | Reuse the `dl` summary shape in `resources/js/pages/Manage/Pickups/Show.vue`, `formatMoney`, and the existing `resources/js/pages/Wallet/Statement.vue` movement table.                                                                                                                                                                                |
| Navigation                             | Add the Manager basket destination to `resources/js/composables/useAppNavigation.ts` under the existing cooperative section.                                                                                                                                                                                                                           |

## Route, role and state inventory

| Page                     | Role               | States and distinct patterns                                                                                                                                                                       |
| ------------------------ | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Finance/Baskets/Index`  | Manager            | Populated, empty, long household; list rows, status badge, create action.                                                                                                                          |
| `Finance/Baskets/Create` | Manager            | Active households, none, validation error, processing; selection form and disabled submit.                                                                                                         |
| `Finance/Baskets/Show`   | Manager            | Populated and empty drafts, cancelled draft, validated pending collection, collected, insufficient-stock error, processing, long product; stock rows, form, balance, status and collection action. |
| `Wallet/Statement`       | Manager and Member | Basket source in populated statement, empty statement, long source text. Manager destination links only.                                                                                           |

The 56 explicit cases cover each page/role baseline at 375 and 1280 px, light and dark, 100% text, plus 1024 px, both themes, 200% text. Collected is also measured at 375 px in both themes. Empty and cancelled detail have four cases each at 375 px, both themes, 100% and 200% text. Special states use the narrow or enlarged combination with highest overflow or focus risk. State assertions check draft editing, empty and cancelled current contents and zero total, pending collection, collected read-only history, errors, disabled processing, Manager basket links and distinct Member basket source text. The Show content selector measures summary dt/dd values, and the populated Show focus path includes Remove, stock selection, quantity, Add and Wallet link. Computed assertions check the single pilot shell font, heading contrast and 44 px button targets where buttons exist. The fixture data is deterministic. It records a real Create form POST with a visible validation error or pending response, and a Show collection PUT with a pending response. HTTP authorization and persistence are verified in PHP tests; browser geometry alone is not authorization evidence. No modal or overlay is added. Below-fold form and action controls remain in the focus path. The fixture applies appearance and text size; reduced motion uses the runner's preference handling. A system-appearance case is omitted because the explicit light/dark matrix exercises the same theme classes; a fallback-font case is omitted because the shipped Nunito face loads in every case and no new font fallback is introduced.

The responsive Wallet table keeps five semantic column headers in the DOM while its existing container rule visually clips the header at narrow widths and shows matching cell labels. The measurement selector checks visible rows/cells and source text/link; a structural assertion keeps all five headers. A Member statement has no main-content action at T55, so its keyboard path checks the visible sidebar trigger. The fixture excludes layout breadcrumb links from page-specific focus markers.
