# Q&A — A zero-quantity line in a validated basket still blocks redistribution (T59)

Asked at the T59 (DRA-214) code checkpoint on 2026-11-03. A validated base keeps a 0-quantity line for a
product not received at validation time. After a late arrival (cherries 0 → 2, into the late basket), a
later correction 2 → 3 is a redistribution.

**Q: Does a validated basket block that redistribution only when its quantity is > 0, or with any line of the product, even at 0?**
A: "Any line, even at 0 (literal)". The correction is rejected, nothing changes, and staff use individual
basket corrections. R18 as approved already says this, so the spec does not change.
