## 2026-11-06T07:20:39.069Z · Change

Task: DRA-241

ADR 0002 rule 3 (`docs/adr/0002-sqlite-as-the-only-database.md`) and T78 in `tasks/sqlite.md`: the database no longer carries CHECK constraints. Tables are built with the schema builder; partial unique indexes stay as portable raw `create unique index ... where`; types, `not null`, foreign keys and unique indexes remain. The domain objects enforce the former CHECK invariants and their tests prove them. T78 must confirm a domain or Application test covers each dropped CHECK (adding the guard and test if none does) and removes database tests that only exercise a CHECK. The `btrim` port disappears with the basket adjustment CHECK.

Why: Laravel 13's schema builder cannot declare CHECK constraints and SQLite cannot add them after `create table`; the user chose to keep invariants in the domain rather than write raw `create table` SQL or extend the grammar. See the Q&A entry of the same date (DRA-241).
