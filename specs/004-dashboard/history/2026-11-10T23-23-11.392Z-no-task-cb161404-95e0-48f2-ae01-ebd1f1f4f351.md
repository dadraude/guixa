Q18 — Freshness

Q: Should the dashboard update whenever someone opens or returns to it, and offer a refresh action with a “last updated” time? While it stays open, the list would remain unchanged until refreshed.

Example: if another volunteer validates a reception, its old dashboard item may remain until refresh; opening it must show the current state.

Recommendation: yes for the first slice. This makes freshness explicit and keeps the dashboard predictable.

A: Q18 yes

Decision: refresh dashboard data on opening or returning to the page; offer explicit refresh and show last-updated time. No background refresh while the dashboard stays open. Destination screens show current state even when a dashboard item is stale.
